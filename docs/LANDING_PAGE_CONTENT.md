# Landing 页文案总表（可编辑稿）

本文件按 `app/page.tsx` 从上到下的板块顺序整理**当前线上文案**。你改好后把整份或相关段落丢给助手，并说明要改「简体 / 繁体 / 全部」，我们会对应更新 `lib/dictionaries.ts` 或组件里的硬编码字串。

---

## 使用说明

| 项目 | 说明 |
|------|------|
| **主文案文件** | `lib/dictionaries.ts` 内 `translations['zh-CN']` 与 `translations['zh-TW']` |
| **Hero 副标题格式** | 换行用 `\n`。`~文字~` = 删除线；`_文字_` 或 `*文字*` = 加粗 + 品牌蓝 |
| **语言** | 站点支持简体与繁体；改文案时通常两区都要同步改（除非你指定只改一种） |
| **未进字典的文案** | 见文末「组件内硬编码」；改那些需动对应 `.tsx` 文件 |
