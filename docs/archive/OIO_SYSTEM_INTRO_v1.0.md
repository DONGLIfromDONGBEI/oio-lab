## zh-CN（1.0）

- sectionTitle: OIO系统拆解

1) heading: Output：用AI定制个人专属素材
- body: 别再背单词，别再学那些跟你无关的"废话"。我们直接从你真实生活出发，确保你每一分钟的努力都精准命中未来的使用场景。
- bullet:
  - 告别中式蹩脚英文：大胆从容地记录你最真实的生活点滴，用AI深度改写将其瞬间转化为母语级的定制素材。
  - 拒绝流水账：用日记捕捉目标、拆解计划。让日记不再是琐碎记录，而是你加速实现目标的执行工具。

2) heading: Imprint：让大脑自然习得"你的个人专属素材"
- body: 如果你写完就忘、开口就卡，那不是记忆力的问题，而是因为你没有给大脑一个"高效习惯"。
- bullet:
  - 自然习得逻辑：拒绝死记硬背，用大脑最习惯的"语意词块"方式，让地道表达在你的思维中自然生长。
  - AI专属 WebPlayer：听你所写，说你所听。一键生成你日记的原声音频，让你在最熟悉的语境中精准打击听力与发音痛点，告别"看懂听不懂、说不出"的困扰。

3) heading: Output：把英文变成实现理想的工具
- body: 学了十年还是"哑巴英语"，是因为你从未真正用英文解决过生活中的真实问题。
- bullet:
  - 在输出中完成自我迭代：不再重复枯燥复习，而是完成上面两步的吸收后再次输出，更加自信地讲好英文。
  - 让英文真正为你所用：在使用中明确目标、化解情绪、将问题转化为行动计划，用英文改变生活，为自己创造自信。

4) heading: Bonus. 创始社群：并肩前行的力量
- body: null
- bullet:
  - 主题话题活动：每一期课程都有专属的主题活动。作为创始成员，你将拥有持续参与未来每一期活动、在社群中持续成长的特权。
  - 见证彼此的蜕变：在一群同频者的陪伴下，见证自己在英文的世界中从逻辑混乱到清晰、从畏缩迟疑到从容自信的蜕变。
